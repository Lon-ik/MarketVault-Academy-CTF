# MarketVault Academy — Руководство по запуску

Это руководство поможет скачать, установить и запустить MarketVault Academy CTF, даже если вы раньше не работали с Docker.

## 1. Что такое MarketVault Academy?

MarketVault Academy — образовательная CTF-платформа для изучения Web Security и практики поиска уязвимостей в специально созданной лабораторной среде.

Проект включает несколько микросервисов, базы данных и веб-интерфейс. Для удобного запуска всех компонентов используется Docker Compose.

**Важно:** платформа содержит намеренно уязвимые сервисы. Используйте её только локально или в изолированной учебной среде. Не публикуйте её в открытый интернет без предварительной подготовки и защиты инфраструктуры.

## 2. Системные требования

Перед началом убедитесь, что у вас установлены:

- Git — для скачивания исходного кода.
- Docker — для запуска контейнеров.
- Docker Compose v2 — для управления всеми компонентами проекта.

Рекомендуется иметь:
- 4 ГБ свободной оперативной памяти или больше.
- Несколько гигабайт свободного места на диске.
- Стабильное интернет-соединение для первоначальной загрузки Docker-образов и зависимостей.

## 3. Установка необходимых инструментов

### Windows

1. Установите Git: https://git-scm.com/downloads/win
2. Установите Docker Desktop: https://docs.docker.com/desktop/setup/install/windows-install/
3. При установке Docker Desktop используйте WSL 2, если он доступен.
4. Запустите Docker Desktop и дождитесь завершения инициализации.

Откройте PowerShell или Windows Terminal.

### Linux

Установите Docker Engine и Docker Compose Plugin, следуя официальной инструкции для своего дистрибутива:

https://docs.docker.com/engine/install/

Для Debian и Ubuntu также ознакомьтесь с настройкой Docker Compose Plugin:

https://docs.docker.com/compose/install/linux/

Git можно установить через пакетный менеджер своего дистрибутива.

После установки Docker убедитесь, что служба запущена. При необходимости настройте права доступа к Docker согласно официальной документации.

### macOS

1. Установите Git: https://git-scm.com/downloads/mac
2. Установите Docker Desktop: https://docs.docker.com/desktop/setup/install/mac-install/
3. Запустите Docker Desktop и дождитесь его полной загрузки.

## 4. Проверка установки

Откройте терминал и выполните:

```bash
git --version
docker --version
docker compose version
```

Если все три команды выводят версии установленных программ, можно переходить к следующему шагу.

Также проверьте, что Docker работает:

```bash
docker info
```

Если команда завершилась без ошибки подключения к Docker daemon, всё готово.

## 5. Скачивание проекта

Откройте терминал и выполните:

```bash
git clone https://github.com/Lon-ik/MarketVault-Academy-CTF.git
```

Перейдите в папку проекта:

```bash
cd MarketVault-Academy-CTF
```

Теперь у вас есть локальная копия исходного кода.

## 6. Подготовка конфигурации

В корневой папке проекта находится файл `.env.example` с демонстрационными настройками.

Создайте на его основе `.env`:

**Linux / macOS:**

```bash
cp .env.example .env
```

**Windows PowerShell:**

```powershell
Copy-Item .env.example .env
```

Файл `.env` содержит настройки подключения к базам данных и внутренним сервисам.

Значения по умолчанию предназначены исключительно для локального учебного запуска. Не используйте их при публичном развёртывании.

## 7. Запуск платформы

Убедитесь, что терминал находится в корневой папке проекта.

Выполните:

```bash
docker compose up -d --build
```

Docker Compose автоматически:

1. Соберёт необходимые образы.
2. Загрузит недостающие зависимости.
3. Создаст контейнеры.
4. Настроит внутреннюю сеть.
5. Запустит сервисы и базы данных.

Первый запуск может занять некоторое время.

Проверить состояние контейнеров можно командой:

```bash
docker compose ps
```

Для просмотра логов:

```bash
docker compose logs -f
```

Чтобы выйти из просмотра логов, нажмите `Ctrl + C`. Это не остановит контейнеры.

## 8. Открытие платформы

После успешного запуска откройте браузер:

http://localhost:3000

Если всё запустилось корректно, вы увидите интерфейс MarketVault Academy.

Для демонстрационного входа используются следующие учётные данные:

| Роль | Логин | Пароль |
|---|---|---|
| Student | `student` | `student123` |
| Admin | `admin` | `admin123` |

Это демонстрационные учётные записи. Не используйте их в публичной среде.

## 9. Управление проектом

Основные команды Docker Compose:

**Посмотреть состояние контейнеров:**

```bash
docker compose ps
```

**Посмотреть логи всех сервисов:**

```bash
docker compose logs -f
```

**Перезапустить сервисы:**

```bash
docker compose restart
```

**Остановить проект:**

```bash
docker compose down
```

**Остановить проект и удалить контейнеры:**

```bash
docker compose down
```

Данные постоянных томов при обычном `down` сохраняются.

Не используйте `docker compose down -v`, если не хотите удалить данные томов проекта.

## 10. Возможные проблемы

### Docker daemon is not running

Docker не запущен.

- Windows / macOS: откройте Docker Desktop и дождитесь его загрузки.
- Linux: проверьте состояние службы Docker.

### Port is already allocated

Один из портов, необходимых проекту, уже используется другой программой.

Проверьте процессы, занимающие порты `3000` и `4000`, и освободите их либо измените конфигурацию публикации портов.

### Container exited или сервис не запускается

Посмотрите логи:

```bash
docker compose logs
```

Для конкретного сервиса:

```bash
docker compose logs api-gateway
```

Замените `api-gateway` на название нужного сервиса.

### Изменения в коде не применяются

Если вы меняли исходный код и хотите пересобрать контейнеры:

```bash
docker compose up -d --build
```
